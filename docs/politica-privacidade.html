Política de Privacidade

Aplicativo: Quiz Estudo
Última atualização: 11 de agosto de 2026

Esta Política de Privacidade descreve como o aplicativo Quiz Estudo coleta, utiliza, armazena e protege as informações dos usuários. O aplicativo tem finalidade educacional e foi desenvolvido para auxiliar estudantes na resolução de questões, no acompanhamento do desempenho e na preparação para atividades relacionadas à Olimpíada de Matemática.

Ao utilizar o aplicativo, o usuário declara estar ciente das práticas descritas nesta Política de Privacidade.

1. Dados coletados

O aplicativo pode coletar e armazenar os seguintes dados informados pelo próprio usuário:

  • Nome completo;
  • Endereço de e-mail;
  • Data de nascimento;
  • Série escolar;
  • Informações de login e autenticação;
  • Pontuação obtida no aplicativo;
  • Progresso nas questões;
  • Histórico de acertos e erros;
  • Nível atual do participante;
  • Título ou classificação dentro do sistema de aprendizagem.

A senha do usuário é utilizada somente para autenticação e é gerenciada pelo serviço de autenticação do Supabase. O aplicativo não exibe nem armazena a senha em texto aberto.

2. Dados de uso e desempenho

Durante a utilização do aplicativo, podem ser registrados dados relacionados ao desempenho do usuário, como questões respondidas, acertos, erros, pontuação, sequência de acertos, ranking e progresso por nível.

Esses dados são utilizados para permitir o funcionamento dos recursos educacionais do aplicativo, como acompanhamento da evolução, cálculo de pontuação e organização do ranking.

3. Dados coletados por colaboradores administrativos

O aplicativo também pode possuir uma área administrativa destinada ao cadastro de questões. Usuários autorizados, como professores, colaboradores ou organizadores, podem cadastrar enunciados, alternativas, imagens e informações de nível e dificuldade das questões.

O acesso à área administrativa é restrito a usuários autorizados mediante login e código de acesso.

4. Finalidade do uso dos dados

Os dados coletados são utilizados para as seguintes finalidades:

  • Permitir o cadastro e login de usuários;
  • Identificar o participante dentro do aplicativo;
  • Organizar os usuários por série escolar e nível;
  • Disponibilizar questões adequadas ao nível do participante;
  • Calcular pontuação e desempenho;
  • Exibir ranking dos participantes;
  • Evitar repetição de questões já acertadas;
  • Permitir acompanhamento da evolução do estudante;
  • Melhorar a organização pedagógica do aplicativo;
  • Manter a segurança e integridade do sistema.

5. Compartilhamento de dados

O aplicativo não vende dados pessoais dos usuários.

Os dados podem ser processados por serviços utilizados para o funcionamento do aplicativo, especialmente o Supabase, que é usado para autenticação, banco de dados e armazenamento de informações do sistema.

Os dados também podem ser acessados por administradores autorizados do projeto, quando necessário para fins de suporte, organização, correção de problemas, acompanhamento pedagógico ou manutenção do sistema.

6. Serviços de terceiros utilizados

O aplicativo utiliza serviços de terceiros para funcionar corretamente:

  • Supabase: utilizado para autenticação de usuários, armazenamento de perfis, questões, progresso, pontuação e ranking.
  • GitHub Pages: utilizado para hospedagem de páginas públicas do projeto, como esta Política de Privacidade.
  • Google Play: utilizado para distribuição oficial do aplicativo Android.

7. Segurança dos dados

São adotadas medidas técnicas para proteger os dados dos usuários, incluindo autenticação, controle de acesso, políticas de segurança no banco de dados e restrição de permissões administrativas.

O banco de dados utiliza regras de acesso para limitar o que cada usuário pode visualizar ou modificar. Dados administrativos e chaves sensíveis não devem ser expostos no aplicativo ou em repositórios públicos.

8. Recursos anti-cheat

O aplicativo pode utilizar recursos de segurança durante a resolução das questões, com o objetivo de preservar a integridade das atividades. Esses recursos podem incluir bloqueio de captura de tela no Android, detecção de saída da tela de prova e encerramento da rodada quando o sistema anti-cheat for acionado.

Esses recursos são usados apenas para proteger a atividade educacional dentro do aplicativo. O aplicativo não acessa câmera, microfone, localização ou arquivos pessoais do dispositivo para essa finalidade.

9. Imagens e arquivos

A área administrativa pode permitir o envio de imagens para compor questões. Essas imagens são utilizadas apenas para fins educacionais dentro do aplicativo.

Os colaboradores responsáveis pelo cadastro devem evitar enviar imagens que contenham dados pessoais, documentos, rostos de pessoas ou materiais sem autorização de uso.

10. Crianças e adolescentes

O aplicativo possui finalidade educacional e pode ser utilizado por estudantes em idade escolar. Quando utilizado por menores de idade, recomenda-se que o uso ocorra com ciência dos responsáveis legais, professores ou instituição responsável pela atividade educacional.

O aplicativo coleta apenas dados necessários para identificação educacional, organização por série, acompanhamento de desempenho e funcionamento do sistema.

11. Retenção dos dados

Os dados podem ser mantidos enquanto forem necessários para o funcionamento do aplicativo, acompanhamento do desempenho, manutenção do ranking, organização das atividades educacionais ou cumprimento de obrigações administrativas.

Caso o usuário solicite a exclusão de seus dados, a solicitação será analisada e realizada quando tecnicamente possível e de acordo com as necessidades do projeto.

12. Direitos do usuário

O usuário pode solicitar informações sobre seus dados, correção de informações incorretas ou exclusão de dados pessoais, quando aplicável.

Para realizar uma solicitação, o usuário deve entrar em contato pelo e-mail informado nesta Política de Privacidade.

13. Dados que o aplicativo não coleta

O aplicativo não coleta, de forma intencional, os seguintes dados:

  • Localização em tempo real;
  • Contatos do dispositivo;
  • Mensagens SMS;
  • Histórico de chamadas;
  • Fotos pessoais fora das imagens enviadas voluntariamente na área administrativa;
  • Dados bancários;
  • Informações de cartão de crédito;
  • Áudio do microfone;
  • Imagem da câmera.

14. Publicidade e monetização

O aplicativo, em sua versão atual, não utiliza anúncios publicitários e não vende informações pessoais dos usuários para terceiros.

15. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada para refletir mudanças no aplicativo, em seus recursos, em seus serviços de terceiros ou em exigências legais e de plataformas de distribuição.

Quando houver alterações relevantes, a data de atualização será modificada nesta página.
